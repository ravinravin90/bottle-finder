      How this would work for real

      A small service reads each store's POS every few minutes through its API (for Square, the Catalog and Inventory endpoints per location; Clover works the same way with one merchant per store). It matches products across stores by UPC, so the same bottle shows as one row even when the five stores spell its name differently.

      Search runs on our side, not the POS, which is why "jd", "titos handle" and typos all work. Nothing is written back to the POS. Everything on this page is example data: real brands, invented stock, prices and barcodes.
